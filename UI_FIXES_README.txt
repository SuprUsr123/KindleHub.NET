KindleHub Client — merged UI fixes

This archive is the full KindleHubClient project from the original uploaded project,
with the Arcade and game UI fixes merged together.

Included changes:
- Arcade page UI refresh (catalog header, search/filter controls, richer game cards).
- READY badge foreground fixed to use SystemAccentColor.
- Shared game window reworked with centered, per-game board sizing.
- Connect 4 board sizing/labels fixed in the shared view model.
- Tower of Hanoi board rendering redesigned with pegs/disks/base instead of block-text stacks.

The archive is intended to be extracted as a replacement/restore of the project tree.

2026-09-30 keyboard/gameplay follow-up
- 2048 movement axes were corrected; left/right now move horizontally and up/down vertically.
- GameWindow keyboard handling now runs in the tunnel phase, so focused buttons cannot consume game keys.
- Hangman now accepts physical A-Z keys as well as its on-screen alphabet.
- Wordle now accepts physical A-Z, Enter, and Backspace. Its on-screen keyboard was rebuilt as a proper 10/9/7-key QWERTY layout instead of being squeezed into five columns.
- Minesweeper now has a much stronger covered/revealed visual distinction and revealed cells stay enabled so their visual state is not dimmed by Avalonia's disabled styling.

2026-09-30 game correctness follow-up
- Sudoku now only reports a solve when rows, columns and 3x3 boxes are all valid, and editable cells cycle 1-9 then blank correctly. The filled counter includes givens and user entries.
- Nim now lets one tap make any legal multi-counter move in a row and has a mathematically correct computer reply using the zero-nim-sum strategy.
- Lights Out boards are generated by legal presses from the solved state, guaranteeing that every starting board is solvable.
- Minesweeper now uses normal primary-click-to-open / secondary-click-to-flag behavior, lets flags be toggled correctly, and reveals all mines when the player loses.
- Reversi now handles forced passes for either side instead of getting stuck when the human has no legal move, and only legal moves are enabled on the board.
- Peg Solitaire now ends when no legal jump remains and only calls a one-peg finish "perfect" when the final peg is in the centre.
- Tower of Hanoi now treats picking up and immediately returning a disk to the same peg as a cancelled selection rather than a counted move.
- Number Slide no longer visually enables tiles across a row boundary when they are not actually adjacent to the gap.
- 2048 direction handling was corrected so right/down movement mirrors the input direction instead of merely reversing row/column iteration.
- Snake redraws mutate the existing bound cells so the board updates reliably, keeps the board tappable for touch steering, and treats a completely filled board as a win rather than placing food on the snake.
- Mastermind feedback now shows the actual exact/colour-only counts instead of a single dot for any non-zero count.
- Wordle now rejects non-words from a built-in common-word list without consuming a guess.
- The shared game interface supports secondary/right-click actions; GameWindow routes those actions to games such as Minesweeper.

Score submission remains stubbed as before; these changes do not implement or alter the server submission flow.
